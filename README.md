# Cafeterías de La Paz

Propuestas web para **Kibou**, **Bodega** y **Le Tasse**, en La Paz, Baja California Sur.

## Abrir las páginas

Descarga el archivo HTML de la cafetería y ábrelo con Safari, Chrome o Firefox. Cada HTML incluye sus estilos, scripts e imágenes.

- **kibou.html**: sitio completo de Kibou, con animación de café vinculada al desplazamiento.
- **bodega.html**: sitio completo de Bodega, con persiana interactiva y transición de día a noche.
- **le-tasse.html**: sitio completo de Le Tasse, con álbum de fotografías animado.

GitHub muestra el código de los HTML; para ver el diseño, descarga el archivo y ábrelo en el navegador.

## Código fuente organizado

El archivo **cafeterias-la-paz-github.zip** contiene 57 archivos: cada sitio en su carpeta (`kibou`, `bodega`, `le-tasse`), con HTML, CSS, JavaScript, imágenes y documentación. Descomprímelo para editar o publicar cada sitio por separado. No requiere compilación. Puedes servir la carpeta con `python3 -m http.server 8000`.

## Contenido

Son propuestas de diseño y no implican afiliación oficial con los establecimientos. Las fuentes públicas y notas se encuentran en los sitios y documentos LEEME. Horarios, cartas y precios pueden cambiar. Las marcas y fotografías corresponden a sus titulares; su inclusión no concede derechos adicionales de reutilización. Los recursos generados de Kibou están documentados en su carpeta assets.
